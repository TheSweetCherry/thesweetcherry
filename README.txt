THESWEETCHERRY — WEBSITE V1

UPLOAD TO GITHUB
1. Extract this ZIP.
2. On GitHub's 'Drag files here' page, upload the CONTENTS of this folder:
   index.html
   quiz.html
   paint.html
   photobooth.html
   styles.css
   common.js
   README.txt
   assets folder
3. Commit the upload.
4. Then enable GitHub Pages from Settings > Pages.
